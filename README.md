# TeDB
Đây là ứng dụng chuyển đổi dữ liệu trong tài liệu, hình ảnh thành cơ sở dữ liệu trong posgresDB, quy trình thực hiện như sau:
tài liệu / hình ảnh --> chuyển thành dạng json --> lưu dạng json --> so sánh, tìm những key/value giống nhau, key giống nhau và giá trị khác nhau. --> lưu dạng json -> thiết kế bảng phù hợp --> lưu vào PóGressDB
